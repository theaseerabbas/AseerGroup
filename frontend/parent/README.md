# The Aseer Group — Parent Website

Corporate parent website for **The Aseer Group** (`https://theaseergroup.com`), built with TanStack Start, React, TypeScript, and Tailwind CSS.

## Local Development

```bash
npm install
npm run dev
```

## Available Scripts

- `npm run dev` — Start the local Vite development server
- `npm run build` — Build the production bundle
- `npm run preview` — Preview the production build locally
- `npm run lint` — Run ESLint
- `npm run format` — Format source files with Prettier
- `npm run test` — Run Vitest unit/routing tests
